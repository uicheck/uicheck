# @uicheck/core

> Source: [README](https://github.com/uicheck/uicheck/blob/main/packages/core/README.md)

## Install

```bash
npm install @uicheck/core
```

Shared protocol runtime and types for uicheck platform clients.

Platform packages:

- `@uicheck/web` for browser DOM pages
- `@uicheck/taro` for Taro Mini Program pages
