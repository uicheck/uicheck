# UI Check Docs

UI Check has one connection model: AI clients connect to MCP, and app runtimes connect over WebSocket. Configure @uicheck/mcp in the AI client first, then choose the runtime package for your app platform.

## AI client

- [@uicheck/mcp](./mcp/) - Configure @uicheck/mcp so AI can call list_clients, capture_page, and inspect_elements.

## Platform integrations

- [@uicheck/web](./web/) - Browser DOM client for uicheck
- [@uicheck/taro](./taro/) - Taro Mini Program client for uicheck
- [@uicheck/rn](./rn/) - React Native client for uicheck
- [uicheck_flutter](./flutter/) - Flutter runtime client for uicheck
- [uicheck_android](./android/) - Android native runtime client for uicheck
- [uicheck_apple](./apple/) - Apple native runtime client for uicheck
- [@uicheck/core](./core/) - Shared protocol runtime and types for uicheck clients
