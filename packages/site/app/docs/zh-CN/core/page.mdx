# @uicheck/core

> Source: [README](https://github.com/uicheck/uicheck/blob/main/packages/core/README.zh-CN.md)

## Install

```bash
npm install @uicheck/core
```

uicheck 平台客户端共享的协议 runtime 和类型。

平台包：

- `@uicheck/web` 用于浏览器 DOM 页面
- `@uicheck/taro` 用于 Taro 小程序页面
