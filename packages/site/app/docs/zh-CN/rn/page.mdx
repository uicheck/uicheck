# @uicheck/rn

> Source: [README](https://github.com/uicheck/uicheck/blob/main/packages/rn/README.zh-CN.md)

## Install

```bash
npm install @uicheck/rn
```

React Native 客户端。`initUiCheck` 会在安装时接入 React / JSX 创建流程，让 AI 通过 `@uicheck/mcp` 读取真实运行时元素的布局、文本、`testID` 和无障碍标签。

```ts
import { initUiCheck } from '@uicheck/rn'

initUiCheck({
  socket: {
    url: 'ws://127.0.0.1:17322/socket'
  }
})
```

## 截图

React Native 截图依赖宿主应用。需要支持 `capture_page` 时传入返回 PNG base64 的 `screenshot` 函数。

```ts
initUiCheck({
  screenshot: async () => ({
    mimeType: 'image/png',
    base64: await captureAppAsBase64()
  })
})
```
